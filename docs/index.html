자주 묻는 것

궁금할 만한 것들

어떤 원격 도구에서 되나요?

Jump Desktop · macOS 기본 화면 공유 · Parsec 에서 실측 확인했습니다. 전송 방식이 서로 다른 세 도구입니다. 화면 공유는 모든 맥에 이미 들어 있으니 따로 설치하실 게 없습니다.

나머지 도구도 원리상 됩니다 — 키를 보내지 않고 각 기기가 자기 입력 소스만 바꾸기 때문에 원격 도구가 경로에 없습니다. 다만 아직 실측하지 않았습니다. 설정에서 쓰시는 앱을 골라 주기만 하면 됩니다.

키 입력을 훔쳐보는 건 아닌가요?

아닙니다. 읽는 건 지금 입력 소스가 한글인지 영문인지 뿐이고, 무엇을 쳤는지는 알지 못합니다.

이건 말로 하는 약속이 아니라 직접 확인하실 수 있는 사실입니다 — 시스템 설정 → 개인정보 보호 및 보안 → 손쉬운 사용·입력 모니터링 목록에 macbridge 가 없습니다. macOS 에서 그 권한 없이 키 입력을 읽는 것은 기술적으로 불가능합니다.

저는 Caps Lock 으로 안 바꾸는데요?

상관없습니다. macbridge 는 키를 전혀 보지 않습니다 — "입력 소스가 바뀌었다"는 신호만 듣습니다. 오른쪽 Command 든, 메뉴바에서 마우스로 클릭하든, 직접 매핑한 키든 똑같이 동작합니다.

Ctrl+Space 도 됩니다. 원격 도구에 따라 이 키가 상대 맥으로 넘어가기도 하는데, 그때는 macbridge 가 되돌리지 않고 따라갑니다. 다만 이 키는 상대 맥의 입력을 가끔 꼬이게 합니다. 그럴 땐 메뉴바 「지금 정렬」 을 누르세요 — 타이밍이 없어 언제 눌러도 한 번에 풀립니다. 손이 키보드에 있으면 Caps Lock 톡톡(1초 내 두 번)도 같은 일을 합니다.

계속 무료인가요?

지금은 무료 베타입니다. 반응을 보고 정식 버전은 유료로 전환될 수 있습니다. 전환하게 되면 베타를 써 주신 분들께 먼저 안내드립니다.

기기끼리 어떻게 통신하나요?

같은 네트워크나 Tailscale 같은 VPN 위에서 UDP 로 짧은 메시지를 주고받습니다. 연결 코드가 맞고 허용된 대역에서 온 것만 처리합니다. 서버를 거치지 않습니다.

인터넷 없이도 되나요?

됩니다. 기기끼리 IP 로 닿을 수만 있으면 되고, 외부 서버에 접속하지 않습니다.

세 대 이상도 되나요?

됩니다. 새 기기에서 연결 코드를 붙여넣으면 나머지 기기들에게도 알아서 인사합니다.

설치하고 코드 한 번 붙여넣으면 됩니다
