설정 파일을 열 일은 없습니다. 전부 메뉴바에서 됩니다.

설치

연결할 기기 모두에 설치합니다

  1. DMG 를 받습니다

    Releases 에서 MacBridge-x.y.dmg

  2. 응용 프로그램으로 드래그

    DMG 를 열면 드래그할 자리가 보입니다.

  3. 실행합니다

    메뉴바에 한 또는 A 가 뜹니다. 동기화 데몬은 앱이 알아서 등록합니다.

"확인할 수 없는 앱" 경고가 뜨면 — 베타에는 Apple 공증이 아직 없어서 뜹니다. 처음 한 번만 아래를 하면 그다음부터는 그냥 열립니다.
  1. 앱을 한 번 실행해 봅니다. 경고가 뜨면 그대로 닫으세요. 이 단계를 건너뛰면 다음 단계에 항목이 나타나지 않습니다.
  2. 시스템 설정 → 개인정보 보호 및 보안 → 맨 아래 보안 항목까지 스크롤
  3. "MacBridge 이(가) 차단되었습니다" 옆 그래도 열기 → 암호 입력
⚠ macOS 15 Sequoia 부터 우클릭 → 열기 방식은 없어졌습니다. 다른 곳에서 그 방법을 보셨다면 옛날 안내입니다.
메뉴바 아이콘이 안 보인다면 — Ice·Bartender 같은 메뉴바 정리 앱을 쓰시나요? 새 아이콘이 숨김 영역에 들어갔을 수 있습니다. 숨김 영역을 펼친 뒤 ⌘ 를 누른 채 드래그해 꺼내면 위치가 유지됩니다.

기기 연결

연결 코드를 한 번 옮기면 됩니다

기기끼리 같은 연결 코드를 나눠 가져야 서로를 신뢰합니다.

  1. 코드를 만듭니다

    이미 설치된 기기에서
    설정 → 기기 → + 새 기기 추가…

  2. 붙여넣습니다

    새 기기에서
    설정 → 기기 → 기존 기기에 연결…

  3. 끝입니다

    연결 코드와 기기 목록이 자동으로 맞춰지고, 나머지 기기들에게도 알아서 인사합니다.

mb1.100.64.0.3.8765.482917
코드는 만드는 순간 클립보드에 자동 복사됩니다. 한 번 쓰면 닫히고, 120초가 지나거나 5번 틀리면 폐기되니 그때는 1번부터 다시 하세요.

쓰는 법

평소 쓰시던 대로 바꾸면 됩니다

양쪽이 같이 바뀝니다. 두 번 누를 필요가 없습니다.

macbridge 는 키를 전혀 보지 않습니다 — "입력 소스가 바뀌었다"는 신호만 듣습니다. 그래서 Caps Lock, 오른쪽 Command, 메뉴바 클릭, 직접 매핑한 키 — 무엇으로 바꾸든 똑같이 동작합니다. 손쉬운 사용 권한이 필요 없는 이유이기도 합니다.

Ctrl+Space 를 쓰셔도 됩니다. 원격 도구에 따라 이 키가 상대 맥으로 넘어가기도 하는데, 그때는 macbridge 가 되돌리지 않고 따라갑니다. 어느 쪽이든 언어는 맞습니다.
다만 이 키는 상대 맥의 입력을 가끔 꼬이게 합니다. 한글 모드인데 영문만 나오거나 자소가 흩어질 때가 있습니다. 둘 중 편한 쪽으로 푸세요 —
  1. 메뉴바 → 「지금 정렬」 ⭐ 가장 확실합니다. 누르는 타이밍을 맞출 필요가 없어서 언제 눌러도 한 번에 됩니다.
  2. 캡스락 톡톡 — 손이 키보드에 있을 때 빠릅니다. 다만 1초 안에 두 번이어야 하고, 지구본 키처럼 느린 키는 놓칠 수 있습니다.
전환 키로 캡스락을 안 쓰셔도 복구 키로는 쓸 수 있습니다 — 원격 창이 앞에 있어도 로컬에 먹는 유일한 키라서요.

아예 겪고 싶지 않으시면 이 단축키를 꺼두셔도 됩니다 — 시스템 설정 → 키보드 → 키보드 단축키 → 입력 소스 → "이전 입력 소스 선택" 체크 해제.

자소분리가 났을 때

1순위 · 가만히

1~5초 안에 자동복구

어긋난 걸 감지하면 정렬하고, 창을 한 번 전환해 꼬인 세션을 끊습니다. 화면이 한 번 깜빡이면 복구된 겁니다.

2순위 · 확실하게

메뉴바 → 「지금 정렬」

타이밍을 맞출 필요가 없어 언제 눌러도 한 번에 됩니다. 전 기기를 정렬하고 세션을 리셋합니다.

안 풀릴 때 기댈 곳은 여기입니다.

3순위 · 빠르게

한/영을 톡톡 (1초 내 두 번)

손이 키보드에 있을 때 빠릅니다. Caps Lock 은 원격 창이 앞에 있어도 먹는 유일한 키라 가장 잘 통합니다.

⚠ 1초 안에 두 번이어야 합니다 — 지구본 키처럼 반응이 느린 키는 놓칠 수 있고, 그때는 위의 「지금 정렬」을 쓰세요.

셋 다 결국 같은 일을 합니다 — 한/영을 맞추고 창을 한 번 전환해 꼬인 입력 세션을 끊는 것. 손으로 하면 다른 창을 클릭했다 돌아오는 것과 같습니다.

메뉴 항목

  • 지금 정렬 — 전 기기를 내 언어로 맞추고 꼬인 세션을 풉니다.
  • IME 동기화 — 잠시 끄고 싶을 때.
  • 연결 테스트 — 기기별 왕복 시간. 안 될 때 원인을 좁히는 데 씁니다.
  • 자소분리 관측 창 — 문제를 재현해 기록으로 남길 때.

원격 도구를 왜 고르나요

그 앱으로 원격할 때만 한/영을 맞추기 위해서입니다. 안 그러면 로컬에서 일하다 한/영을 바꿔도 다른 기기까지 따라 바뀝니다.

목록에 없는 도구를 쓰신다면 + 지금 쓰는 원격 앱 자동 감지 를 누르고, 5초 안에 원격 창을 앞으로 가져오면 알아서 잡습니다. 번들 ID 를 몰라도 됩니다.
고르는 걸 잊으셨어도 괜찮습니다. 목록에 없는 앱으로 원격하다 한/영이 어긋나면, 메뉴바가 먼저 알려 주고 [원격 도구에 추가] 버튼을 띄웁니다. 아니라고 답하면 그 앱은 다시 묻지 않습니다.

잘 안될 때

연결 테스트부터 눌러 보세요

기기별 왕복 시간을 재서 원인을 좁혀 줍니다.

상대 기기가 계속 "오프라인"

❌ 응답 없음 이면 아래 중 하나입니다.

원인확인
방화벽 시스템 설정 → 네트워크 → 방화벽. macOS 방화벽은 외부 수신만 조용히 막아서 증상이 "아무 일도 안 일어남"으로만 나타납니다
연결 코드 불일치설정 → 고급 → 연결 코드가 양쪽 같은지
IP 가 바뀜설정 → 기기 목록의 주소가 지금 주소와 맞는지
상대 기기가 꺼짐상대 기기에서 메뉴바 아이콘이 보이는지

한/영이 전혀 안 맞춰짐

설정 → 원격 도구 탭에서 지금 쓰는 원격 앱이 체크돼 있는지 보세요. 아무것도 안 골랐다면 항상 동기화되고, 엉뚱한 앱만 골랐다면 그 앱을 쓸 때만 동기화됩니다.

잠긴 화면의 기기

화면이 잠긴 맥은 비밀번호 입력을 위해 입력 소스를 영문으로 강제합니다. macbridge 는 그걸 알고 잠긴 기기는 건드리지 않습니다. 정상 동작입니다.

알아두면 좋은 것

  • 추가 권한이 필요 없습니다. 키 이벤트를 만들지 않고 각 기기가 자기 입력 소스만 바꾸기 때문입니다.
  • 한글 조합 중에 전환하면 마지막 글자가 사라질 수 있습니다. macOS 입력기 동작이라 구조적으로 못 없앱니다.
  • Cmd·Ctrl 이 눌린 채 굳는 건 원격 도구 쪽 문제입니다. 각 조합키를 한 번씩 톡 눌렀다 떼면 풀립니다.

해결되지 않으면 알려 주세요

메뉴바 → 「문의하기…」 를 쓰시면 됩니다. 무엇이 안 되는지 적고 보내면 진단 정보가 함께 첨부돼서, 설명만으로 못 찾던 원인도 대개 바로 보입니다.

무엇이 담기는지 보내기 전에 보실 수 있습니다. 창의 「무엇이 담기는지 보기」 를 누르면 첨부될 내용이 그대로 나옵니다. 연결 코드는 담기지 않고, 기기 이름·IP·다른 앱 이름은 가려서 나갑니다 — 원격 도구 이름만 남습니다(그게 있어야 원인을 찾을 수 있어서요).

앱이 직접 보내지 않습니다. 메일 앱이 열리면 내용을 확인하고 직접 보내시면 됩니다. 보내주신 정보는 문제 해결에만 쓰고 보관하지 않습니다.
